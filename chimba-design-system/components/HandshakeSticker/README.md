# HandshakeSticker

La manito 🤝 como sticker con borde blanco: el sello de cada colaboración Cliente × Chimba.

**El consumidor provee:** `<img class="ch-sticker">` con `Stickers/handshake-light` (o `handshake-yellow`) y `alt` vacío si es decorativa, o `alt="en colaboración con"` si reemplaza palabras.

- Tamaños: `.ch-sticker--sm` (64px, en líneas de texto y tarjetas), base (120px), `.ch-sticker--lg` (220px, portadas de caso).
- Va **entre** dos marcas, o al final de un manifiesto junto al logo de Chimba.
- Siempre girada unos −6°. No la deformes, no la recortes, no la pongas como emoji de texto.
