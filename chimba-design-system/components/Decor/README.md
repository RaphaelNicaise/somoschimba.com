# Decor

Los gestos geométricos de fondo: la hoja, la línea de recorrido y el bloque verde de esquina.

**El consumidor provee:** elementos vacíos posicionados en absoluto dentro de la sección, con `aria-hidden="true"`.

- `.ch-leaf`: hoja de contorno (verde por defecto, `.ch-leaf--blue`, o `.ch-leaf--fill` para un bloque sólido). También como marco detrás de una foto.
- `.ch-track`: línea fina que baja y dobla con curva `radius-track`. Dale ancho y alto para dibujar el recorrido; conecta secciones o rodea una galería.
- `.ch-corner-block`: rectángulo verde que sangra desde un borde de la pantalla.
- Un tipo de gesto por sección. Nunca encima del texto de lectura.
