# Footer

Cierre de página en azul Chimba: llamado a escribir con resaltado verde y una fila de datos.

**El consumidor provee:** `<footer class="ch-footer">` con `p.ch-footer__cta` (incluye un `.ch-mark`), un botón opcional y `.ch-footer__row` con mail, redes y año.

- El CTA en voseo: “¿Arrancamos? **Escribinos.**”
- Links en verde sobre azul (6:1). El logo, si va, en texto blanco: el archivo del logo es azul y no se ve acá.
