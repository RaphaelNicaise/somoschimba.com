# SectionTitle

Encabezado de galería: bloque verde que sangra desde el borde izquierdo y el título en itálica azul (“Key visual 2”).

**El consumidor provee:** `<h2 class="ch-section-title">` con un `<span class="ch-section-title__text">`. Ponelo pegado al borde izquierdo del contenedor (sin padding) para que el bloque sangre.

- Para agrupar piezas dentro de un caso: “Key visual 1”, “Redes”, “Papelería”.
- Acompañalo con `.ch-gallery` debajo.
