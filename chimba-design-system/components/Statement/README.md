# Statement

Bloque de manifiesto: una frase grande en azul con una o dos palabras resaltadas y, abajo, la firma con la manito.

**El consumidor provee:** `<section class="ch-statement">` (o `.ch-statement--brand` para fondo verde) con un `p.ch-statement__text` que incluya `.ch-mark`, y opcionalmente `.ch-statement__sign` con logo del cliente + sticker + wordmark de Chimba.

- Una idea, 6–14 palabras. Remate resaltado.
- Gris para el relato, verde para el golpe de efecto (máximo uno por página).
- Mucho aire: no agregues botones dentro; el CTA va en la sección siguiente.
