# Scribble

Óvalo verde dibujado a mano que rodea el logo o una palabra para señalarla.

**El consumidor provee:** un contenedor `.ch-scribble` con el contenido a rodear y, adentro, `<img class="ch-scribble__stroke" src="Shapes/oval-scribble-green" alt="">`.

- Uno por pantalla. Se apoya mejor sobre gris o blanco.
- Rodea cosas cortas: el logo, un número, un CTA, una palabra.
- Queda detrás del contenido (`z-index: -1`), así no tapa el texto.
