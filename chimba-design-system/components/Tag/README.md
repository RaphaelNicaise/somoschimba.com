# Tag

Etiqueta en MAYÚSCULAS sobre una franja verde levemente torcida, para nombrar el tipo de trabajo.

**El consumidor provee:** `<span class="ch-tag">` con una o dos palabras. `.ch-tag--lg` para la versión de portada (arriba a la derecha de un caso, como “REBRANDING”).

- Usos: servicio del caso (Rebranding, Redes, Key visual, Campaña), categoría del filtro de portfolio.
- Sobre gris, blanco o noche. Sobre verde no se distingue: ahí usá `.ch-mark--inverse`.
- No lo uses como botón; si es clickeable, que sea un filtro con estado claro.
